Confirm POST /api/v1/mobile/busapp rejects bad payloads with an immediate 400 instead of hanging the full ~138s. Needs AWS UAT access (SSO profile uat, account 806100285832) to pull the server token.

Step 1 · Log in to AWS

aws sso login --profile uat

Step 2 · Pull the server token + run the checks

Paste the whole block. The token goes in the token header — that's what authenticates to ezd-core (not a driver login token).

TOKEN=$(aws secretsmanager get-secret-value --profile uat --region us-east-1 \
  --secret-id ezrd/uat/ezd-core --query SecretString --output text \
  | jq -r '.EZRD_SERVER_TOKEN' | cut -d, -f1)

CORE=https://core.ezd-uat.runpathwise.com/api/v1/mobile/busapp
H=(-H "Content-Type: application/json" -H "client: testqa" -H "app: busapp" \
   -H "mobile: 363DC37D-2509-4E65-8D6A-F5C155DEBDD8" -H "token: $TOKEN")

curl -s -o /dev/null -w "health        -> HTTP %{http_code}\n" \
  https://core.ezd-uat.runpathwise.com/health

for d in \
 '{"method":"INVALID_METHOD","url":"/api/routes/mine","headers":{},"data":{}}' \
 '{"method":"GET","url":"/routes/mine","headers":{},"data":{}}' \
 '{"method":"GET","url":"/api/routes/mine","headers":null,"data":{}}' \
 '{}'; do
  curl -s -w "HTTP %{http_code}  %{time_total}s  " "${H[@]}" -d "$d" "$CORE"; echo
done
