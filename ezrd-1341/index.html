EZRD-1341 — Duplicate Route Fix · Test Steps

Confirm that approving/creating a route that matches an existing driverless route merges into it (no duplicate) and fills in the driver. Tenant: testqa (UAT).

Buses to use (already exist in testqa)

  • • No default driver: FPB-005, FPB-012, Bus-030
  • • Has a default driver: Bus-001, Automation Bus-1

Make a "driverless route": Routes → ＋ → enter a Name, pick a no-default-driver bus, leave Driver blank, set a recurrence, add one trip + one stop, Save. Confirm via ⋮ → General that the Driver input is empty.

1 · Driverless route merges + driver filled in (main fix)

  1. Routes → make a driverless route named QA1341-A on bus FPB-005 (Driver blank). Save.
  2. Route Builder → ＋ → Name QA1341-A, Vehicle FPB-005, Driver = QA Driver, same recurrence. Add a trip + stop → Save → Submit.
  3. Approve the request (New/Change Requests).
  4. Routes → open QA1341-A → ⋮ → General.
Expect: still one route named QA1341-A (no duplicate); Driver field now shows QA Driver (was blank).

2 · Driver comes from the bus's default driver

  1. Make a driverless route QA1341-B on bus Bus-001 (Driver blank). Note Bus-001's default driver — shown as the greyed "default: …" hint.
  2. Route Builder → ＋ → Name QA1341-B, Vehicle Bus-001, Driver = Bus-001's default driver, same recurrence. Add trip + stop → Save → Submit.
  3. Approve → open QA1341-B → ⋮ → General.
Expect: one route QA1341-B (no duplicate); Driver filled in with the default driver.

3 · Different driver than the bus default → new route

  1. Make a driverless route QA1341-C on bus Bus-001 (Driver blank).
  2. Route Builder → ＋ → Name QA1341-C, Vehicle Bus-001, Driver = a different person than Bus-001's default, same recurrence. Add trip + stop → Save → Submit → Approve.
Expect: a new route is created (now two QA1341-C); the original stays driverless.

4 · Request has no driver → new route

  1. Make a driverless route QA1341-D on bus FPB-012 (Driver blank).
  2. Route Builder → ＋ → Name QA1341-D, Vehicle FPB-012, Driver blank, same recurrence. Add trip + stop → Save → Submit → Approve.
Expect: a new route is created (two driverless routes are not merged).

5 · Different name → new route

  1. Make a driverless route QA1341-E on bus Bus-030 (Driver blank).
  2. Route Builder → ＋ → Name QA1341-E-DIFF (different), Vehicle Bus-030, Driver = QA Driver, same recurrence. Add trip + stop → Save → Submit → Approve.
Expect: a new route QA1341-E-DIFF is created; QA1341-E is untouched.

6 · Same fix via the Routes tab (not Route Builder)

  1. Make a driverless route QA1341-F on bus FPB-005 (Driver blank).
  2. Routes → ＋ → create another route: Name QA1341-F, Vehicle FPB-005, Driver = QA Driver, same recurrence. Add trip + stop → Save.
  3. Open QA1341-F → ⋮ → General.
Expect: one route QA1341-F (no duplicate); Driver now shows QA Driver.

7 · Normal route still merges (regression)

  1. Make a route QA1341-G on bus Bus-001 with a driver assigned (not blank). Save.
  2. Route Builder → ＋ → Name QA1341-G, Vehicle Bus-001, same driver, same recurrence. Add trip + stop → Save → Submit → Approve.
Expect: merges into the existing route — no new route created.
